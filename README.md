# TECHNOLOGIES

¡Bienvenido/a! Este repositorio es una colección práctica y visual de mi trayectoria como estudiante
de desarrollo de software. Aquí comparto ejercicios, proyectos pequeños, apuntes y recursos que he
construido mientras aprendía tecnologías web y de backend.

---

**Descripción breve:**

Este proyecto recoge ejemplos y ejercicios organizados por tecnologías: HTML, CSS (y SASS), JavaScript,
TypeScript, Python, React, Node.js, Docker, Bash, Git y SQL. Está pensado como un portafolio de estudio
y referencia personal.

---

**Estructura del repositorio**

- [01_HTML](01_HTML/): Ejercicios y ejemplos de HTML (estructura semántica, formularios, multimedia, tablas, documentación de patrones).
	- Muestras y assets en [01_HTML/Multimedia](01_HTML/Multimedia/) incluyendo imágenes y ejemplos de `picture`/`srcset`.
- [02_CSS](02_CSS/): Ejemplos de CSS y SASS, iconos y plantillas (carpeta `Carta` con estilos y maquetación).
- [03_JS](03_JS/): Javascript básico e intermedio, DOM, prácticas y ejercicios (carpeta `JS_BASIC`, `JS_INTERMEDIO`).
- [04_TYPESCRIPT](04_TYPESCRIPT/): Ejemplos de TypeScript, definiciones y proyectos `TSX`.
- [05_PYTHON](05_PYTHON/): Scripts y apuntes de Python desde fundamentos hasta módulos y APIs.
- [06_REACT](06_REACT/): Proyectos y ejemplos con React + Vite, componentes de muestra.
- [07_NODEJS](07_NODEJS/): Notas y estructura básica para Node.js y servidores Express.
- [08_SQL](08_SQL/): Ejemplos y estructuras para bases de datos MySQL/Postgres.
- [09_GIT](09_GIT/): Comandos y notas sobre Git.
- [10_DOCKER](10_DOCKER/): Notas y Dockerfile de ejemplo.
- [11_BASH](11_BASH/): Apuntes de Bash y scripts básicos.
- [12_LOGIC](12_LOGIC/): Ejercicios de lógica y resolución de problemas.
