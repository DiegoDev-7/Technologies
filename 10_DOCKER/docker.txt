
	Para descargar imagenes entrar a:

	https://hub.docker.com


	docker init 																				(Inicia el proyecto con algunos comandos predeterminados).


	-----Download Images-----

		docker images																			(Muestra las imagenes descargadas).

		docker pull name																	(Instala una imagen).

		docker pull name:version													(Instala una imagen con una version especifica).

		docker image rm name:version											(Elimina una imagen con su version).



	-----Create Contains, start Container and Logs-----


		---Create Container---

		docker create name																(Crea un contenedor de una imagen (Hay que tener una imagen descargada*)).

		docker create --name monguito mongo								(Permite crear un contenedor con el nombre que nosotros le quisieramos asignar y la imagen).

		docker create -p27017:27017 --name monguito mongo	(Permite crear un Puerto Host y un Puerto Contenedor (No es necesario añadir el primer 27017)).


		---Start Container---

		docker build -t name:tag .												(Permite crear una imagen de Docker y asignarle un nombre y una etiqueta especificos al mismo tiempo y con el "." para incluir nuestro proyecto).

		docker start NAME or ID														(Inicia el contenedor con la id).

		docker ps																					(Muesta los contenedores corriendo).

		docker ps -a																			(Muestra todos los contenedores (Incluye los que no estan corriendo)).

		docker stop id																		(Detiene el conteendor).

		docker rm NAME or ID															(Permite eliminar un contenedor con el nombre o el id).


		---Logs---

		docker logs NAME or ID														(Permite mostrar los logs de un contenedor).

		docker logs --follow NAME or ID										(Permite mostrar los logs de un contenedor y quedarse escuchando a nuevos logs (El contenedor tiene que estar running)).



	-----Easy Start Container-----

		docker run name																		(Busca la imagen, si no la encuentra la descarga y crea un contenedor y muestra los logs (No arranca el contenedor)).

		docker run -d name																(Busca la imagen, si no la encuentra la descarga y crea un contenedor, no muestra los logs y arranca el contenedor).

		docker run --name monguito -p27017:27017 -d mongo	(Busca la imagen, si no la encuentra la descarga y crea un contenedor, no muestra los logs y arranca el contenedor con el puerto especificado y el nombre asignado).


		-----ENV-----

    -e 																								(Se utiliza para incluir las variables de entorno).

		--env-file .env 																	(Se utiliza para incluir el archivo .env de las variables de entorno a el correr el contenedor).


	-----Network-----

		docker network ls																	(Muestra todas las redes disponibles en el sistema Docker).

		docker network inspect [name]  										(Muestra toda la informacion detallada de una red especifica de Docker).

		docker network create [name]											(Permite crear una nueva red).

		docker network rm name														(Permite eliminar una red).			

		docker create -p HOST_PORT:CONTAINER_PORT --name CONTAINER_NAME --network MI_RED name_image:tag 
		
																											(Permite crear un contenedor asignarle un puerto al contenedor, asignarle un nombre ).


	-----Compose-----

		Tenemos que tener 1 archivo obligatorio para armar nuestro proyecto el cual es dockerfile; Este archivo lo que nos permitira hacer es construir, 
		manipular y decidir que queremos que se ejecute en nuestro contenedor.


		-----Files-----

		docker-compose.yml																(Permite definir los servicios del proyecto, db, puertos, variables etc; Es el que orquesta los contenedores).

		dockerfile																				(Este archivo le permite decir a Docker como tiene que construir la imagen de nuestra app).


		docker compose up																	(Permite levantar la aplicacion).

		docker compose -f file.dev up											(Permite levantar una aplicacion pero con otro archivo totalmente diferente al docker-compose.yml).
	
		docker compose down																(Permite apagar y limpiar todo lo que se levanto en la aplicacion).

		docker compose logs -f														(Permite ver los logs).


	-----System-----

		docker system df 																	(Nos muestra todos los archivos, volumenes, imagenes y contenedores que tenemos en docker con su almacenamiento y estadisticas adicionales).

		docker system prune 															(Borra todos los contenedores).

		docker system prune -a 														(Borra todas las imagenes).
